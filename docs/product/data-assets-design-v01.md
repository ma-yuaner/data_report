让使用者回答四件事：数据在哪里、字段和业务口径是什么、改动会影响哪里、缺什么由谁补。主要使用者为数据开发、分析人员和业务口径维护人员；岗位到正式权限的映射待确认。

## 规则与主路径

### AS01–AS03：找表与理解表

身份按环境/连接实例/库/schema（适用时）/对象构成，底账保留完整身份和原大小写，连接别名只是展示名。同名表不得跨实例去重。实例指纹用来区分来源，地址和凭据不展示。原型按快照中的连接与实例指纹标识。

目录默认列出当前快照全部可见范围，选库后显示当前筛选计数与全快照计数。搜索名称、中文用途与库，多个词同时匹配；中文输入期间不重建输入框，手动查询。主题域与负责人在确认前显示“待确认”，不按表名自动发布分类。正式目录服务端分页，筛选/列宽/页码返回保留，导出复用全站任务且绑定查询快照。

表详情提供业务用途、对象类型、层级及证据、统计粒度、业务主键、时间字段及含义、负责人、更新契约、字段字典、索引/键、依赖与关联指标。字段区列出原字段名、类型、中文含义、可空性、键、分区属性、业务规则与敏感级别；本次未采集的内容留待确认。不提供业务行预览或任意SQL执行入口。

lywz现有ODS17/DWD34/DWS68/ADS43/DIM15按名称仅标“候选”；确认用途后才标业务分层已核对。default三张表先待分类。MySQL不强行归ODS，bi_前缀不自动等于ADS。允许ODS直接到DWS、DWD直接到ADS和同层依赖。

### AS04–AS05：血缘与变更影响

血缘默认当前表一跳，上游在左、下游在右，箭头方向明确，节点可进入详情。节点显示连接/库/表及对象状态；未解析端点显示原引用，不伪造成实体。大分支分页或展开，不默认画1067节点全图。字段级血缘后续独立覆盖，不能把表依赖推广成每列都有映射。

每条依赖必须可查看证据类型、脚本/任务、版本或哈希、定位、解析时间、两端核验状态。证据分为实库视图定义、ETL源码、DataX配置；运行事件另接真实任务批次/版本/时间。定义依赖不是运行成功，外键与JOIN条件另设结构/关联视图，不混入加工流向。

“影响分析”沿有向边下游遍历，去重、防环、默认最多5跳，超出范围可继续展开。标记为“已知定义范围内的潜在影响”，显示遍历范围和未解析前沿，不能宣称全量影响已穷尽。仅运行证据过滤下，当前应显示“尚未采集运行证据”，不能显示已验证零影响。自读取写入的同表增量节点保留证据，遍历时不无限循环。

### AS06：治理闭环

入口是缺口清单：按缺表用途、字段注释、未声明主键、分层待分类和血缘端点分别筛选，表/字段/依赖边的数量分开，各类可能重叠。本次2184字段缺注释涉及344对象，不能称为2184张表；47张表未声明主键不代表存在重复数据。

建议路径：解释缺口→定位对象/证据→填写业务字典草稿→核对前后差异→按授权发布字典修订→回看来源与版本。物理结构保持只读。填业务主键不创建数据库主键，编辑中文用途不执行COMMENT DDL；这些数据库变更仍需另外授权。

正式字典发布规则、负责人范围和是否需要另人审核属于待确认业务规则。本版仅演练本地草稿，不伪装审批已接入。保存需版本校验，冲突保留草稿并提示重新核对，成功反馈后再改变界面；发布版本不可覆盖历史。重新采集不覆盖人工字典，不自动消除仍存在的物理注释缺口。

### AS07、AS10：采集与状态

页面只读已发布快照；刷新页面不扫描全库。发起采集为显式后台任务，复用现有作业进度/取消语义，限制同源并发、连接超时和一次覆盖规模；连接配置只在服务端私密环境中引用。

记录排队/运行/成功/部分成功/失败、发起者、来源、扫描范围、起止时间、对象/字段数、错误诊断码、差异、发布版本。失败保留上一成功快照并显示旧版本；部分成功按来源标覆盖，聚合版本记录每个来源的批次，不能让旧来源冒充本次成功。权限或范围变化导致的“未见对象”不直接删除，先形成缺失候选核对。

结构采集时间、源任务成功时间、业务数据更新到、字典核对时间分别展示。未知保持未知，未同步不补0。结构变化只产生新增/类型变化/缺失候选，不自动修改业务口径或下游任务。

### AS08–AS09：保留与权限

既有指标公式/条件/粒度/时间/NULL说明保持原实现；新增引用映射，未匹配引用保留原文与待核验状态。分析任务引用SQL指标资产编号及源码版本，任务数不等于指标数。

权限建议分为查看元数据、维护字典、发布字典、发起采集、查看受限结构；绑定项目现有菜单与服务端权限，不预设全员可见所有实例。原型查看者/维护者仅模拟。未授权对象不因图谱路径泄露名称、注释或源码；返回可见范围提示，影响分析也受同一权限限制。内网HTTP下复用现有能力，避免依赖安全上下文专用API。

## 概念数据与接口交接（建议，非DDL）

| 数据对象 | 负责的事实 | 唯一性/版本边界 |
|---|---|---|
| 连接引用与覆盖范围 | 引擎、逻辑名、实例身份、允许扫描库 | 私密连接引用不包含账号密码 |
| 采集批次与快照清单 | 每源覆盖、成功/失败、聚合发布版本 | 失败尝试与成功快照分开 |
| 物理对象与字段快照 | 结构、注释、键、分区、类型 | 批次×稳定对象身份×字段 |
| 业务字典修订 | 用途、粒度、主键含义、负责人、时效定义 | 对象×修订号，和物理快照解耦 |
| 依赖证据与任务引用 | 两端或未解析引用、证据、版本、定位 | 关系ID与证据ID分开，重复证据不膨胀关系数 |
| 运行事件 | 任务版本、输入/输出快照或分区、结果、时间 | 真实任务批次，不从文件存在生成 |
| 缺口与核对记录 | 触发依据、处理草稿、发布/复核历史 | 保留触发快照，不因填写草稿伪造闭环 |

候选接口职责：目录分页与筛选、对象详情/字段、局部上下游/有界影响、证据定位、缺口查询、字典草稿及发布、采集任务及快照版本。正式路径和权限名在开发交接时与现有API统一，不把本文件候选当已提供接口。现有GET资产目录兼容期保留原消费者，逐步接入快照读模型。

不在本轮预建业务表或迁移SQL。实施DDL时另按中文表/列字典与SQL资产归档约定交付，并单独取得落库证据。

4. 第三批：接实际调度/任务运行证据及字段级映射，建立按授权范围的影响分析。

优先级为建议，不构成用户已批准开发范围；不要求先全部补完业务字典才让目录可用。
