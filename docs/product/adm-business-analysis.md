# ADM 业务分析规划

2026-11-13，用户提出后续建设；本文件为方案，尚未开发或上线。参考现有 ComprehensiveAnalysisLiveView.vue 的时间筛选、维度比较和逐层定位，使用 ADM 自身业务口径。

## 使用路径

日期与时间口径 → 业务概览 → 按维度比较 → 点击异常分组追加筛选 → 查看主单列表 → ADM详情及订单明细。页面保留筛选条件与面包屑，可返回上一层；表格、趋势及导出使用相同口径与权限。

首期建议维度：航司、供应商、平台、业务分类、罚单原因类型、负责组长、操作员、问题归因、处理阶段及申诉结果。供应商/航司/业务分类/罚单原因来自主单，平台/操作员/申诉结果来自明细；历史缺字段单独列为「未填写」，不能默认成其他。

## 指标与统计粒度

| 指标 | 粒度及建议口径 | 下钻内容 |
|---|---|---|
| 新增ADM主单数 | 按主单ID去重；可选下发日期或创建日期 | 对应主单列表 |
| ADM金额 | 默认冻结人民币金额；主单分析用主单金额，明细维度用分摊后的明细金额 | 金额组成与未分摊提醒 |
| 明细数与处理积压 | 明细ID去重；按当前状态快照 | 待办理及负责人 |
| 申诉成功率 | 建议按明细最终有效结果，成功/(成功+失败)，排除处理中及不申诉；历史多轮保留记录 | 成功/失败订单及历史轮次 |
| 不申诉比例 | 建议不申诉/(不申诉+已完成申诉)，分母可下钻核对 | 原因及问题归因 |
| 待匹配/待回款/逾期 | 各自明细状态，回款金额用有效未作废回款记录 | 阻塞原因、责任人与时间 |
| 办理时效 | 分配、接受、提交、审核的事件时间；拒单/重派与转派单独统计 | 操作时间线 |

## 防止分析误导

- 主单与明细一对多，不能关联后重复累加主单总额。主单数量可按涉及该维度的主单去重，但跨平台组的主单数不具可加性，须说明。
- 拆单金额不等于主单总额时，不把明细金额冒充完整ADM金额；显示主单总额、已分配金额和差额。
- 原币金额按币种分组，人民币用原单冻结汇率；不跨币种直接相加。不使用今日汇率重算历史。
- 当前积压是快照，不能据此伪造历史每日积压。若需要历史趋势，依操作事件重建或新增日快照，另行验证。
- 已完结主单仍允许基础信息更正，首期按当前资料展示；历史归属分析需要可审计的时间版本。
- 结果查询失败/数据源未接通不计作未录入差异单或匹配成功。附件不进入指标宽表。
- 正式模块需要独立adm.analysis权限及明确的数据范围，不能自动把「我的待办」权限扩成全公司分析。
