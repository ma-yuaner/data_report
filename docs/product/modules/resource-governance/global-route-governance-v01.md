## RG01 准入核对

- 航线全集取当前有效售卖配置、观察期实际入口请求/调用（补抓配置之外的流量）和全局名单的并集。有效售卖配置尚未接入时，标为「仅覆盖有流量航线」，无法判断零流量的售卖覆盖。名单内无售卖、无流量也可查。
- 按有向城市对匹配，机场映射、双向和地理展开遵从交易引擎。当前售卖配置对比当前生效名单，历史流量按请求时间对比当时生效名单。发布过渡期有真实分片生效记录时按分片认定，否则进入待核。
- 入口收到、已放行、已拦截按去重需求计。实际资源调用按调用计，一次需求可对应多次调用。名单外有实际调用列为最高优先级越界。只有入口收到且有充分证据证明已拦截、无放行无调用时，列为「已拦截」；名单外放行但未实际调用单列「放行异常」。名单外有在售配置但无请求另列「配置差异」。数据未覆盖、映射歧义和缺版本归为待核。名单外不计算质量分。
- 越界详情显示命中依据、规则版本、平台/站点及调用路径，工单先定位具体配置或放行路径。没有平台自有名单时，仅反馈实际请求；验价越界独立取证。

## RG02 名单内评分

先确定能操作的最细组合。全局键是有向城市对。诊断分解为 GDS＋PCC＋平台＋站点＋航线，具备证据时细到请求配置 ID 和资源路径。OTA 保留自有维度，缺省的 GDS/PCC 显示不适用。单个渠道或配置低质，优先处置该组合。全局移除须复核该方向所有活跃配置及保护业务。

首版采用可解释的三项分。各项得分 = 权重 × min（实际值 ÷ 同类目标，1）。总分为各项之和，显示分项及分子分母。同类目标按渠道、资源路径和配置类型回测设定。航线总览仅在可比数据中汇总分子分母后重算，混合口径展示分布及高风险配置数。

| 分项 | 演示权重和目标 | 用法 |
|---|---|---|
| 查询成功率 | 30 分，目标 98% | 查询成功 / 查询尝试 |
| 验价成功率 | 30 分，目标 90% | 验价成功 / 验价尝试 |
| 订单产出 | 40 分，目标每万次实际查询调用 10 个关联成功生单 | 同口径可归属的成功订单去重 / 实际调用 × 10000，独立显示生单成功 / 生单尝试 |

- 演示用最近 7 个完整业务日、至少 1000 次实际查询调用、至少 50 次验价尝试，80 分为复核线。低样本、验价零分母、跨阶段归属未证实、数据不完整均不出总分。生产数值需历史分布、基准与误伤回测后确定。
- 对高调用、零验价或零生单独立标「疑似空耗」。完整数据且关联可靠时，零成功生单可确认是零产出。零验价先核曝光和渠道需求、供给、接口故障、同步和归属。空耗信号可进入人工核查，证据充分且护栏通过后才允许提交临时下线。
- 排查同时显示查询、验价、生单各自的请求与成功数，结合故障和同类对照。阶段总量有独立分母，只有可关联请求才能判断实际转化或空耗归因。公司查定比分母仍为出票航段，航段缺失不计算查定比。

## RG03 处置和复盘

**数据治理岗复核 → 技术工单 → 临时下线回执与流量验证 → 到期安排恢复 → 恢复回执 → 完整观察窗 → 保留或复发。**

- 正式动作需记录对象、原因、配置和名单版本、原值、范围、到期时间、影响预估及回滚值。护栏至少含近窗有效订单、重点渠道及替代供给。可读权限、治理权限、技术执行权限、永久关闭审核权限分别校验。
- 执行失败留原状态和原因，可重试同工单。到期进入待恢复，技术回执与流量核对后更新结果。暂停期间的零调用只用于验证执行，恢复后完整窗口才进入评分和复发判定。
- 演示采用「同一配置、同一问题累计两轮临时下线已生效，且各轮恢复后完整观察仍复发」进入永久关闭候选。用治理对象＋规则＋周期去重，重复告警、失败回执、跨版本无可比证据均不计次。生产次数、累计期限、清零条件及保护范围需确认。
- 永久关闭须复核影响和范围，审批后建工单，执行回执与验证一致后标「已永久关闭」。不自动恢复；后续重新准入需独立审核。配置永久关闭与移除全局城市航线是两个对象级动作。
- 复盘按同配置、相同统计口径比较治理前后实际调用、三阶段表现和有效订单/航段，标明版本、样本、替代配置流量及生效前后时间。名单外以越界调用下降到零且正常放行保持为验收目标。

## RG04 数据发布与首期落地

1. **准入清单**。落实生效名单与售卖配置快照、放行/拦截和实际调用凭证。离线日批统一匹配并预聚合全量结果，发布数据日期、完成时间、源覆盖和版本；页面筛选、排序、分页读发布批次。补数按日期和版本可重跑，失败保留上个完整批次并标旧数据。无全量权限时仅返回授权范围。
2. **影子评分**。复用现有三阶段事实，核对事件粒度、去重及关联，回放若干完整周和已知故障/低样本案例。先测覆盖、日增量与查询/加工成本，再定容量目标。结果用于人工复核和标记。
3. **人工闭环**。接入现有事件和工单。创建动作校验权限、当前对象状态和证据版本，相同事件幂等，配置变化重新核对；回传区分执行、实际生效和验证。先试点临时下线与恢复，再开放永久关闭审批。

| 验收编号 | 预期 |
|---|---|
| A01 | 名单外仅收到并全部拦截，与存在实际调用分列；名单外在售无流量仍出现；反向独立 |
| A02 | 名单或数据缺失显示待核；名单内未调用不打零分，零验价显示疑似空耗与证据要求 |
| A03 | 同向两配置分别评分，仅低质配置进入动作；有效订单和保护配置可拦截动作 |
| A04 | 下线失败及重复回执不计次；恢复后证据不足保留观察；达到两轮复发后才出现永久候选 |
| A05 | 永久关闭须审核、执行、验证；关闭后同航线其他健康配置保留 |

本版用合成数据展示决策、三阶段证据与权限流转。正式数据接入前优先核对两项事实：生效名单和售卖配置的权威来源及取数粒度，入口到实际调用、订单的关联和覆盖。业务侧待定为同类分档与阈值、观察与累计周期、保护及全局移除权限。无 SQL。
