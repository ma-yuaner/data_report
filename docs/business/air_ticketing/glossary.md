# 机票业务术语表

以下定义用于当前知识库的概念区分。涉及公司系统字段时仍需建立字段映射。

| 术语 | 当前定义 | 分析注意事项 |
|---|---|---|
| 航司 | 拥有航班、舱位、运价和库存的产品方 | 与出票供应方可能不同 |
| GDS | 聚合和分销航司内容的系统 | 不等于航司库存所有者 |
| NDC | 航空分销接口和内容标准 | 需记录实际聚合方或直连方 |
| 销售平台 | 公司获得下游订单的平台或客户渠道 | 如 OTA、企业客户、TMC |
| 供应商 | 提供报价、库存或出票能力的上游主体 | 公司内部“供应商”范围待统一 |
| 直连 | 系统通过接口完成查询、预订或出票 | 属于操作方式，不是销售平台 |
| 手工 | 人员在界面或官网完成操作 | 属于操作方式 |
| BSP | IATA 账务与结算体系 | 不作为销售渠道维度 |
| PCC | 办公配置或权限标识 | 影响报价、内容和出票权限 |
| PNR | 旅客订座记录 | 一个订单与 PNR 未必一一对应 |
| 客票 | 出票后形成的电子客票 | 与订单、乘机人、航段区分 |
| 航段票联 | 客票中对应某一航段的使用单元 | 航段分析的建议粒度 |
| 前返 | 出票或采购结算时直接体现的返还 | 检查是否已包含在供应净价 |
| 后返 | 满足周期任务后确认的返还 | 分预计、计提、确认、到账、冲销 |
| 航段奖励 | 按满足条件的航段给予的奖励 | 并非所有航司和政策均有 |
| 留钱收入 | 实际保留的固定金额 | 与投放让利、追价让利分开 |
| 投放让利 | 政策投放时主动让给市场的金额 | 成本方向 |
| 追价让利 | 为获得订单动态追加的让利 | 成本方向，规则待确认 |
| 虚拟卡 | 用于采购支付的数字支付工具 | 同时记录返现和全部费用 |
| 自愿退改 | 因客户自身原因发起的退票或改签 | 需按平台、航司、供应规则核算 |
| 非自愿退改 | 因符合规则的航变等原因进行退改 | 必须保留规则和凭证 |
| 航变 | 航班时间、班次或运行状态变化 | 是否满足非自愿条件按规则判断 |
| Open 票 | 尚未使用且仍可能处于有效期的客票 | 不代表公司可以自行退款处理 |
| ADM | 航司或相关结算体系提出的代理业务差异/借项通知 | 公司系统具体范围和分类待确认 |
| 增值服务 | 行李、选座、餐食、保险等附加产品 | 使用净收入而非只看销售额 |

## 待统一的公司内部用语

- “供应商”在不同系统和团队中的范围；
- “渠道”是指销售平台、内容来源还是出票供应；
- “留钱”字段究竟表示收入还是可投放让利；
- “白屏收单”对应的系统、任务和数据字段；
- 自动、半自动、手工、直连、官网、白屏、黑屏之间是否允许多选及优先级；
- ADM 在公司内部是否只指航司 ADM，还是包含平台罚单和其他处罚。
