# 机票业务模型

## 1. 公司在产业链中的位置

本公司在机票业务中承担中游代理和履约角色：从航司、批发商、GDS/NDC 内容源或官网获得产品与出票能力，通过 OTA、企业客户、散客或 TMC 获得订单，完成政策投放、报价、出票、售后、结算和增值服务。

业务经营不只是票面买卖价差。利润和风险可能发生在售前、出票、支付、退改、增值、后返、结算和罚损等多个事件中。

## 2. 必须分开的四类概念

| 分类 | 回答的问题 | 会议中的典型值 |
|---|---|---|
| 销售平台/下游渠道 | 订单从哪里来 | 携程、去哪儿、飞猪、同程、PK、乐飞、企业客户 |
| 内容或采购来源 | 产品和报价从哪里来 | 航司、批发商、GDS、NDC 聚合、航司官网 |
| 操作与出票方式 | 订单如何完成履约 | 直连、手工、自动、半自动、白屏、黑屏、官网出票 |
| 支付与结算方式 | 资金如何支付和清算 | BSP、ARC、授信、月结、虚拟卡 |

分析时不得把“直连/手工”当成销售渠道，也不得把 BSP 或虚拟卡当成产品来源。一个订单可能同时具有销售平台、采购来源、出票方式、支付方式和结算方式五组属性。

## 3. 业务生命周期

### 3.1 售前：政策获取与投放

主要活动：

- 获取航司、供应商、平台的价格和返点政策；
- 识别公布价、私有价、前返、后返、航段奖励和手续费；
- 判断虚拟卡支持、返现和支付费用；
- 计算预期利润、任务门槛和最大可让利空间；
- 配置平台、PCC、航司、航线、舱位、供应优先级、出票说明和退改规则；
- 投放后监控收单、亏损和任务完成进度。

主要风险：返点资料分散、后返未录入 ERP、任务达标概率估计错误、留钱与让利口径混用、退改规则配置错误。

### 3.2 售中：收单、比价与出票

主要活动：

- 接收订单并核对 PNR、票面、税费、旅客和航段；
- 读取政策和出票说明；
- 比较可用供应的实际采购价格、成功率和售后能力；
- 选择供应并出票；
- 处理出票失败、价格变化、换供应和超亏阈值；
- 核对票号和出票时限。

主要风险：只按票量考核、默认供应而未充分比价、价格变化未及时反馈、出票超时、政策责任与出票执行责任混淆。

### 3.3 售后：退票、改签、航变、Open 与增值

主要活动：

- 识别自愿或非自愿退改；
- 根据航司、供应商和平台规则计算退改费用；
- 提交退票或改签、上传凭证、跟踪退款；
- 处理航变、豁免、客票状态和 Open 票；
- 销售行李、选座、餐食、保险、贵宾厅等增值产品；
- 管理退款垫资、客诉、ADM 和平台处罚。

主要风险：平台规则和供应规则不一致、退款周期和垫资、客票状态判断错误、违规转非自愿、未经授权处理 Open 票、违规收费和客诉。

### 3.4 结算：利润最终确认

最终利润需要结合：

- 客户和平台实收；
- 供应商、航司或 BSP 实际结算；
- 前返、后返和航段奖励的实际确认；
- 虚拟卡费用和实际返现；
- 退改退款和垫资回收；
- 增值实收与成本；
- ADM、平台处罚、客诉赔付；
- 汇率和资金成本。

ERP 预估利润不等于财务最终利润。两者差异本身应成为分析对象。

## 4. 核心实体关系

```text
销售平台 ─┐
客户/旅客 ─┼→ 订单 → 乘机人票 → 客票 → 航段票联
政策/PCC ─┤               │         │
供应报价 ─┘               │         ├→ 退票/改签/航变/Open
                          │         └→ ADM/投诉/赔付
                          ├→ 出票履约
                          ├→ 支付/虚拟卡
                          ├→ 增值服务
                          └→ 财务结算/返点/后返
```

政策、订单、客票、航段、售后单和结算项不是同一粒度。跨实体汇总前必须先处理一对多和多对多关系。

## 5. 高风险业务边界

- 自愿退票转为非自愿、航变留单、作废差价和 Open 票可能产生收益，也可能产生合同、平台、消费者权益和 ADM 风险。
- 数据分析可以还原实际发生的金额和路径，但不能因为历史上产生利润就默认其合规、可复制或应推广。
- 未取得客户授权、航司规则、平台规则和内部审批证据时，相关收益必须单列为“高风险/待核验收益”。
- 管理分析至少同时展示收益、退款责任、客诉、罚单、资金占用和潜在追偿，不得只展示毛收益。
