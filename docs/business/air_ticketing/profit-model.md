# 机票业务利润模型

## 1. 使用原则

会议纪要中的利润公式用于识别利润组成，不是已经确认的财务核算公式。正式上线指标前，必须由财务和业务共同确认金额来源、正负号、含税方式、确认时间和冲销规则。

利润分析应区分三种状态：

| 状态 | 含义 | 主要用途 |
|---|---|---|
| 预期利润 | 投放或出票前，根据政策和预计任务达成率测算 | 定价、投放和供应选择 |
| 业务估算利润 | 出票或售后过程中，根据 ERP 已知事件重估 | 运营监控和异常预警 |
| 已结算利润 | 根据实际收付、返点结算、退款、处罚和汇率确认 | 财务复盘和正式经营结果 |

三者必须分列，不能用已结算利润字段回填历史预期，也不能把未达标后返按 100% 计入已结算利润。

## 2. 推荐总公式

在统一币种和统一含税口径下：

```text
订单贡献利润
= 客户/平台确认收入
- 供应采购与票款结算成本
- 平台佣金及渠道费用
- 支付和结算费用
+ 已确认返点及航段奖励
+ 增值服务净收入
+ 售后服务净收入
- 退款、赔付及退改损失
- ADM及平台罚损
- 可归属资金成本
```

“净收入”表示已经扣除对应直接成本。若增值或售后模块提供的是毛收入，则必须同时扣除其采购、退款和履约成本。

## 3. 防止重复计算

### 3.1 票面与采购价

- 公布价和私有价通常是价格属性或采购基础，不应同时作为两笔收入。
- 票面价差可以作为分析解释项，但如果总利润已经使用客户实收减供应结算，不得再把票面价差额外加一次。

### 3.2 税费

- 如果客户实收和供应结算都是含税金额，税费通常已经包含在两端现金流中。
- 若要单独分析税费，必须明确是代收代付、成本、收入还是不可抵扣税负。
- 国内和国际税费规则不同；儿童、国家、航司和行程也可能影响税费。未知税费不能估成统一比例。

### 3.3 返点

- 前返、后返、航段奖励分别记录，防止供应净价已经扣除前返后又重复加回。
- 后返至少记录预计、计提、确认、到账和冲销状态。
- 后返未录入 ERP 时不能默认为 0；应标记“数据缺失”并单独估算影响范围。

### 3.4 留钱、投放让利与追价

- 留钱收入：向客户或平台结算中实际保留的金额，利润方向为正。
- 投放让利：为获得订单主动让出的金额，利润方向为负。
- 追价让利：平台或策略追加的让利，利润方向为负。
- 只有金额语义和来源字段得到确认后才能进入利润公式；名称为“留钱”的字段不能直接决定正负号。

### 3.5 虚拟卡

- 虚拟卡返现与开卡费、充值费、交易费、跨境费分别记录。
- 返现按实际确认状态计算；因余额不足导致的出票失败属于履约异常，不能只看返现率。

### 3.6 售后与退款

- 客户收取的退改费、供应实际扣费、平台佣金、退款赔付分别记录。
- 退票导致的原销售冲销与退票服务收入不能混为一项。
- 同一售后单多次申请、部分退和多航段退必须在事件层去重后汇总。

### 3.7 ADM与处罚

- ADM、平台罚单、投诉赔付和其他处罚分别记录实际金额、计提金额、申诉结果和责任归因。
- 申诉中金额不能既作为确定损失又作为潜在损失重复计入。

## 4. 金额事件最小字段

每一条影响利润的金额事件至少需要：

```text
event_id                 唯一事件编号
event_type               收入/采购/佣金/返点/退款/增值/罚损等
order_id                 订单编号
ticket_no                客票号，可空
coupon_no                航段票联，可空
after_sales_id           售后单号，可空
policy_id                政策编号，可空
supplier_id              供应方
amount_original          原币金额
currency_original        原币
fx_rate                  使用汇率
amount_base              本位币金额
recognition_status       预计/计提/确认/到账/冲销
business_date            业务发生日
recognition_date         财务确认日
settlement_date          结算日
source_system            来源系统
source_record_id         来源记录
rule_or_contract_id      规则或合同依据
updated_at               最后更新时间
```

## 5. 必须支持的利润归因

- 销售平台、内容/采购来源、航司、航线、PCC；
- 政策、政策员、出票员、售后处理人；
- 直连/手工、自动/半自动/手工出票；
- 供应商、支付方式、虚拟卡产品；
- 自愿/非自愿退改、航变、Open、增值类别；
- 正常经营利润、数据待确认金额、高风险收益和风险损失。

人员归因用于定位流程和激励问题，不等同于责任认定。责任判断需结合当时政策、出票说明、可选供应、系统状态和审批记录。
