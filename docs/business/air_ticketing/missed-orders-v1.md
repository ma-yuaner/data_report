# 漏处理订单 V1

来源：用户2026-11-02提供原BI查询、旧表DDL与Excel，确认迁移到`sibebid`后授权开发菜单。漏处理入选定义由原清洗脚本负责，应用不增加成功标记、正差价或舱位判断，不重新清洗。状态：代码实现与本机合成验证；真实表、调度及部署分别验收。

## 页面与数据

- 菜单：智能分析 → 智能投放 → 漏处理订单，路由`/smart-analysis/placement/missed-orders`。
- 固定MySQL `sibebid.bi_downgrade_missed_order_day`，公司`1020`、分析代码`DOWNGRADE_MISSED`；不回退旧库、Hive或演示数据。
- 一行一条源记录，稳定键为原`id`。列表、详情、导出保留历史重复，不用订单号覆盖记录；汇总分别显示记录数及平台+订单号去重订单数。已提供Excel的2122行/1866订单只是迁移基线，不是运行页面硬编码结果。
- 出发/到达字段按用户DDL称“城市”；多值舱位完整展示。平台、任务/业务类型按用户原映射显示名称，未知编码原样保留（例如TVLK、IWOFLY），不丢行。NULL组别显示未填写，空备注显示无备注，差价NULL显示缺失而非0。
- 默认出票日期为本月首日前7天至本月末，按`issue_ticket_time >= start AND < end+1天`查询；单次最多366天。原`business_date`保留追溯，不能作为出票日或默认统计日。
- 订单号完整等值匹配，最多50字符；填写后忽略日期范围，仍保留平台、人员权限及其他筛选。日期、平台、航司、政策员、组别为常用条件，更多筛选包括两端城市、差价上下限、任务/业务类型。
- 默认出票时间倒序、ID稳定次排序；支持差价及ID排序，排序字段白名单、参数绑定、服务端分页（30/50/100）。金额仅展示源差价原值，不命名为损失或利润，不默认汇总差价，不新增币种推断。前端按十进制字符串展示两位小数，避免Number丢失大金额分位。
- 复用PageHeader、FilterPanel、DateRangeField及Ant Design Vue表格/抽屉。默认14列，可选择额外原字段；OTA订单号始终保留。宽表在受高度约束的数据区滚动，分页在表外，备注两行及点击全文。查询使用已应用条件，草稿修改需点击查询；旧请求不能覆盖新结果，进行中修改的草稿不被响应覆盖。选项失败独立展示并可重试，不把失败当空结果。

## 权限与联动

- 新菜单`smart.placement.missed`单独可配置，管理员默认可见；旧的整个智能模块授权按既有组展开规则包含新菜单，不改已有授权方式。新功能权限`smart_placement.missed.export`控制导出，未自动授予业务岗位。
- 人员数据范围复用角色“收单情况”配置`smart_placement.order`：ALL全量；SELF按中台账号已激活ERP绑定的姓名匹配源`policy_operator`；MANAGED增加原`smart_placement`管理成员关系中的激活绑定；WORKFLOW在此源表无流程关系，按SELF处理，不扩大范围。不依据登录昵称或前端传入姓名授予权限。
- 绑定姓名为空或在中台激活绑定中重名时不放行对应姓名；没有映射返回可见范围为空的提示。源表只有政策员姓名，没有员工ID，因此这是绑定姓名映射，不代表已实现ERP员工ID级行权限；上线需核对姓名映射，跨员工重名应先补源员工ID再精确授权。原有绑定/管理关系表缺失时明确不可用，不自动放宽权限。
- 详情展示同平台、同订单号当前可见的最近20条历史记录，并说明截断。进入出票明细带完整订单号、平台及降舱类型，清除目标页面旧筛选，沿用其既有权限与证据入口。
- 有收单菜单权限时，详情复用投放服务读取同平台名+同订单号的真实命中关系，继续执行原收单数据范围，最多100条并说明截断。没有权限不查询；配套表不可用只影响关联区，不让主明细失败。无可见记录不等于从未投放。可进入原投放任务及收单页；收单页新增等值订单号模式，不受当前日期限制，原普通查询保持日期逻辑。

## 导出与接口

复用全局`/api/v1/exports`任务队列、页头任务抽屉、幂等、取消、过期及下载清理；任务类型`smart_missed_orders`。使用成功查询的完整筛选和排序，导出全部匹配源记录、原21字段及名称映射，最多500000条，分批读取。订单号与原ID保留文本，日期原生日期，差价为数值，源文本即使以等号开头也按文本写入，完整备注不截断。

创建、执行和下载分别用服务端可信账号解析器重新核对菜单/导出权限；任务记录服务端生成的人员范围签名，不接受客户端伪造。人员范围变化时要求重新导出，账号停用、撤销权限或跨账号下载均不能获取文件。

| 接口 | 作用 |
|---|---|
| GET `/api/v1/smart-placement/missed-orders` | 筛选、汇总与分页；返回实际filters、source、scope、scopeEmpty、summary、rows、total/page/pageSize |
| GET `/api/v1/smart-placement/missed-orders/options` | 同一日期/订单及权限范围内的筛选项，单项最多250并返回truncated |
| GET `/api/v1/smart-placement/missed-orders/<int:record_id>` | 可见记录、历史及权限内真实命中关系 |
| POST `/api/v1/exports`，kind=`smart_missed_orders` | 复用全局导出任务 |

错误区分400参数不合法、403权限不足、404记录不存在或不可见、503表/查询不可用；没有模拟兜底。
