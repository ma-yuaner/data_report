# 账号管理：编辑与删除授权

- 编辑入口位于账号列表操作列。登录名、密码状态、岗位角色可查看；姓名、邮箱、启用状态和系统管理员身份可保存。角色、个人权限、管理成员、通知身份和密码继续使用独立操作及校验。
- 系统管理员可在「角色与功能 → 系统管理 → 账号管理」勾选「删除账号」，再分配角色；也可直接在单个账号的「个人权限」开启或关闭。没有新默认角色或权限发放。继承权限可由个人关闭覆盖。
- 仅持有删除权限的普通账号可进入账号管理的精简列表，只返回可删账号的 ID、登录名、姓名和启用状态。其他管理接口仍限系统管理员。任何人都不能删除自己或系统管理员。禁用的普通账号也可删除。
- 删除会在同一事务中写入删除标记、禁用账号、撤销旧会话并记录操作审计。删除账号从账号管理和角色成员计数移除，不可再通过账号管理启用。用户名、邮箱、历史业务关联及审计记录保留；无自动回填、清理或恢复入口。

## 数据库前置与字段字典

新增 [auth_deleted_account](../sql/auth-deleted-account.sql) 标记表，区分可启用的禁用账号与已删除账号，不修改共用账号表结构。MySQL / InnoDB / utf8mb4；目标 MySQL 版本与元数据未回读。每行一个已删除的中台账号，按账号 ID 唯一，仅由删除接口写入，登录、会话、账号列表及角色成员计数读取。与 `sys_user` 为逻辑关联，由应用事务负责一致性。

| 字段 | 中文业务含义 | 类型、约束与默认 | 来源与合成示例 |
| --- | --- | --- | --- |
| user_id | 被删除账号的中台 ID | BIGINT UNSIGNED，主键，非空，无默认 | 被删账号 sys_user.id，例如 101 |
| deleted_by | 实际发起删除的中台账号 ID | BIGINT UNSIGNED，非空，无默认 | 当前登录账号 sys_user.id，例如 201 |
| deleted_at | 删除生效的业务时间 | DATETIME，北京时间，非空，无默认 | 删除请求的业务时钟，例如 2026-11-09 10:00:00 |

应用已有 `AUTH_AUTO_CREATE_TABLES` 启动建表入口。若环境关闭自动建表，须由获授权人员在应用库先执行增量 DDL 并核对 `SHOW CREATE TABLE auth_deleted_account`，再启动新版后端。无历史数据迁移。DDL 或权限核对失败时停止切换；回退应用版本时保留标记表和已禁用状态，避免丢失删除证据。此任务未执行目标库 DDL、未部署、未分配真实账号权限。
