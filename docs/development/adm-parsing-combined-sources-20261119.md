# ADM组合材料表头来源与费用校验修复

2026-11-19。用户在T43上传同一ADM的PDF和XLSX后反馈16项校验错误。主会话使用chief-of-staff、PDF、表格和frontend-design，未委派子代理。读取用户指定的两份本地原件，并接收T43已保存candidate/originalCandidate/segments/issues，只在本机离线重放，不再次调用真实模型。

## 实际原因和业务结果

PDF的金额和开具日引用将表头放在数据行之前，与真实PDF读取顺序不符；现仅在每个完整引用行都能在同一指定原文段落找到时，改引用该完整真实段落，不改造原文、不猜数值。原始模型快照和兼容处理记录保留。

Excel的表头和数据行被分别读取，原校验只看到单元格而未核对列名。新增table_sources按文件ID、工作表、行号和列坐标绑定表头与数据；列名RLOC和GDS_RLOC分别证明航司PNR和GDS编码。头行在其他文件/工作表、行坐标不一致、一个明细引用多行、表头不唯一、错列或值不一致时，不自动认定正确。只支持当前读取器生成的坐标行格式；不据此宣称所有表格模板已支持。

实际附件费用列只给出美元符号，没有明确ISO币种，不能据此断定USD。代码从绑定的费用列和单元格保留原数值及列名；没有明确币种时，标准化amount/currency都留空，任务attachmentFees保留可显示的原数值，amountText保留列名加数值及两处来源。当前有效结果撤回模型无依据的USD推断，但原始候选保留以便审计。明确的ISO币种继续校验；明确却不受支持的币种仍报错，不静默接受。

附件单位费用与主单正式金额分开。不同币种只对明确的正式罚单明细作合计风险提示，不把附件单位费用与主单必然不同当成三条重复异常；未知费用币种合并为一条待核对提示。不能推定换汇或用汇率反推币种。交易、币种和原始费用错误分别显示对应字段名称，避免全部写成PNR错误。

页面按行展示附件费用原值、已知或未明确币种、列名来源、数据行来源，并显示航班及航线以区分相同PNR的不同航段。空佣金不重复堆叠。UNTICKETED加Fictitious Name不是虚拟票号声明；虚拟票号仅认明确的票号虚拟声明，保持第一份已验PDF行为。
