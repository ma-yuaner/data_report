将不可覆盖原事实、带源版本/时刻的后续观察、两种相对变化分开。为历史事实版本与票建立稳定关联；每日固定历史上界与配置一致性快照。配置变化识别要覆盖新增规则、适用范围扩大、删除和时间有效性，不能只追原规则ID或父更新时间。未变化只记录成功覆盖，不重复写假变化；部分失败不得发布混合代次。幂等需能区分A→B→A，检查点/待办/发布指针持久化，忙锁不当失败或成功。
