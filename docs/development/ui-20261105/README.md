## 指标交付与缺口

[指标定义JSON](metric-definitions.json)首批29项，每项记录名称、用途、公式、来源、粒度、时间、单位、去重、NULL、更新与权限；另有证据、样例、复算及实现状态。

- 18项为可追溯的既有计算口径，**保持原实现，不重复建设**；其中币种、唯一键、批次完整性等未核验字段已明确标为待核验，不能据此宣布财务口径完整。
- 7项是新增/跨模块统一的候选，公式和合成算例不代表确认；不增加API或正式指标。
- 4项缺数据或可靠来源，不返回伪造结果。
- 全仓587处指标/聚合引用已索引，但尚未全部归并为唯一指标及逐项填写正式定义，29项不代表完整指标数量。
- 风控、综合分析、智能分析/投放、漏处理、目标19项、监控、ADM、HR与行为指标仍需逐领域完成定义；按源码索引追到既有业务契约，不把字段名当口径。各页数量/比率/利润不可跨事实粒度相加。
- NULL问题：旧经营汇总SQL有`COALESCE(SUM(...),0)`，全NULL与无记录可能显示0；原逻辑本轮未改，需先核验是否有覆盖/质量字段，再确定兼容方案。API错误已有NULL状态，与无业务0不能混同。
- 金额问题：旧经营合计经过float；本轮不擅改精度/接口，实库复算需以明细Decimal独立求和并记录展示误差。
- 权限：全站既有通用数据范围未实现部门/平台行隔离；漏处理/智能任务等特殊范围另按原接口核验，不能扩大授权。
- 更新时间：generatedAt是请求/目录生成时刻，缓存命中不会代表新的ETL完成；最新业务日期也不是批次完成证明。

实库没有启动或读取：尚未在本worktree选定已确认外部只读profile，正常应用可能初始化存储，故未直接运行默认生产连接。后续从现有获准接口取脱敏明细/汇总，记录期间与快照；按已确认唯一键查重复，检查空值/未同步，再在原粒度独立聚合、对照API；关联前后记录行数、键基数和金额。禁止只用另一份同样的聚合SQL证明无重复，或把合成复算当实库验收。
