# 内部菜单与整体主题优化

任务 INTERNAL-THEME-20261117，基线为公司GitLab main `f2b2628`。用户在登录页完成后要求优化内部菜单栏及整体主题。本轮采用chief-of-staff、frontend-design，由主会话承担绘景、星桥、明鉴；无子代理。L4评估：修改公共布局但不修改权限规则/数据，采用主会话限定差异及角色渲染检查，不称独立审查通过。

## 设计与范围

视觉延续已确认的公司青绿色标识与登录页。本轮统一内部公共主题，不重构业务页信息架构。

| 区域 | 原状 | 本次实现 |
|---|---|---|
| 菜单栏 | 深蓝底、蓝色选中态、通用图表图标 | 白色侧栏、青绿选中底与左侧标记、公司系统图标、数据中台/乐游五洲品牌位；展开宽232px、收起64px；保持原菜单层级/顺序/名称/权限 |
| 顶栏 | 蓝标签、弱键盘账号入口 | 白色顶栏与品牌色上下文标签、青色头像、原生账号按钮、长用户名省略；面包屑可换行 |
| 公共控件 | 全局蓝色primary | 新theme/platform.ts集中定义Ant Design Vue主题及CSS变量，统一按钮/链接/页签/菜单/表格交互色；危险与成功语义色不变 |
| 内容区/首页 | 蓝色首页主视觉与多处蓝色公共强调 | 浅灰青底、白色面板、深青首页主视觉与公共品牌强调色；内容、指标和查询行为不变 |
| 领域局部强调 | 部分原生按钮焦点、列表当前项和说明使用硬编码蓝色 | 11个既有组件/视图仅替换style中的品牌强调色；模板、业务脚本和图表系列颜色不变 |
| 窄屏/收起 | 已有lg断点、遮罩、Esc、焦点恢复和导出入口 | 原逻辑原样保留；移动端隐藏用户名时保留头像；仅原主菜单保持隐藏滚动条外观，仍可滚动 |
| 登录页 | 已批准的独立浅色登录设计 | 仅补ConfigProvider inherit:false，避免内部主题显式token污染登录；已确认布局、品牌图和验证码流程不变 |

主题配色：品牌原色`#40B3B6`，操作色`#08757A`，选中底`#E5F3F3`，正文`#18383F`，辅助文字`#5B747D`，底色`#F3F7F8`，边界`#DCE7E9`。操作色较登录页略深，用于保证选中底上的菜单文字对比度。使用系统中文字体，无新字体/图片/依赖。

theme/platform.ts同时返回Ant tokens与CSS变量；App更新documentElement变量，使传送到body的弹窗也能使用品牌强调色。AppLayout带同样变量供布局与SSR使用。保留原darkMode状态入口，并提供内部壳/Ant控件深色配色；历史业务页仍有白底局部样式，**不声称全站深色主题完整验收**。

## 不变项与验证边界

菜单主体原文与原版本比较一致；从const appStore开始的路由、权限、导出轮询、窄屏交互、账号/退出行为代码保持一致。品牌入口由模拟按钮div改为原生button，支持原生Enter/Space；账号触发器也使用原生button。未改后端、API、SQL、指标或数据加工，本次无SQL。

检查基于首页、综合分析、登录、公共布局及11个局部style组件。实际Vue/Ant Design Vue服务端渲染覆盖管理员、仅HR菜单账号、收起菜单和深色壳；五个代表SFC及所有改动CSS编译，菜单/业务模板脚本差异检查、主题变量同步、默认/选中状态文字对比度检查均通过。SSR HTML仅是渲染证据，不是浏览器截图或交互实测。

实现中按已安装Ant Design Vue类型核对实际token命名，修正与其他Ant实现不同的字段；浅色选中态文字对比度检查暴露不足后加深操作色，未放宽对比度阈值。隔离夹具先前对换行及ADM既有菜单标题的假设已按真实基线修正，没有改菜单实现来配合夹具。

浏览器按项目AGENTS的Work禁用记录跳过，真实1440/1280/1024宽度、缩放、窄屏滚动/遮罩/焦点、长文本布局及真实账号数据仍待浏览器验收。保留现有业务图表类别/状态颜色，不将所有数据系列改为青色；单页所有视觉细节和全站业务验收不在本次通过声明中。

测试与构建产物在本worktree `.test-artifacts/internal-theme-20261117/`，不提交；checks.json记录命令/退出码/耗时。生产构建复用已验证的任务TEMP入口，不修改公共环境。仅在隔离main副本开发，不混入原fat_cy工作区其他任务。

本次沿用已有主题/公共组件与差异验证方法，无新增通用方法回传MYE；不修改MYE、不部署、不查询CI、不发送外部通知。源码、构建、远端推送及业务验收分别记录。
