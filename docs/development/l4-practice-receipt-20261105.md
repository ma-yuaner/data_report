## 4. 问题、返工和修复验证

1. 权限写死管理员：补目录和跨层动作权限；17项权限反例及原15项鉴权验证。独立审查发现历史抽查跟随编辑权限隐藏；修正只限编辑/保存、保留历史可读；代理复核及模板回归通过。
2. 初始测试误用个人权限接口参数：修测试请求体，未改产品预期；重跑17项通过。扩展原因后旧夹具写死数量/参数位置：按实际接口基数更新夹具，未删边界断言；217项通过。
3. 未确认规则仅有原因名称：先盘点、澄清，不擅自将属性当充分条件；收到用户口径后实现。确认前后快照分别保留，不把后续确认倒写成早已获知。
4. ETL原选单只有两个占位符：改为按已接原因动态绑定；每个新增原因均测试实际Preparation选单及发布，不只测纯函数。
5. 源回放发现正常非空运段误判不完整：核对源字段定义和既有航空段统计范围，修完整性与计数作用域；加入非空运、断链、跨单、重复、未知标记反例；源真实逐单SQL与批量重放一致。
6. 剩余不足为真实历史状态无旧值：记录归因，保持阻断；不通过猜测当前/历史状态清零。未让用户逐单找反例。
7. 发布服务受阻：代码已提交不改写成已推送；工具服务报错不转换为安全结论，也不切换路径绕过。
