# 仓库与运行入口

当前工作区为`D:\data_center_code`，包含两个独立Git仓库。目录可迁移，执行前以`git rev-parse --show-toplevel`为准。

| 仓库 | 责任 | 边界 |
|---|---|---|
| `data_report` | Web、API、应用部署、应用内上传Worker和目标进度任务 | 目标进度任务已有应用部署入口；本轮保留该归属 |
| `data-team-repo` | 独立ETL、数据加工、监控调度和公共数据工具 | 独立提交/验证，不随应用结构调整移动公共工具 |

跨仓交付写明两边提交、表/API契约、执行顺序、执行人、回退步骤。Git提交、CI、部署和业务验收分别记录。应用内部任务统一通过模块入口运行，避免从服务层导入命令行启动脚本。
