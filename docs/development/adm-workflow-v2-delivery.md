# ADM责任流转与待办观察交接

2026-10-25。本轮用户授权复用现有代码开发并核对四张既有表；[唯一开发契约](../product/adm-workflow-increment-v2.md)。下列为代码与本机验收结果，不代表生产部署、业务会议确认或全PRD完成。

## 已完善

| 能力 | 实际交付 |
| --- | --- |
| 主单协调 | 新单明确协调账号，默认本次创建人；可授权更换，保留创建审计。更换后原创建人不再凭createdBy永久看全单。旧单未指定协调人时兼容创建者并标明 |
| 转交确认 | 首次分配后接单；已有承办的再次分配进入待确认交接，不立即换人。接受/驳回/取消、交接摘要、回应、时间和历史持久化 |
| 分段责任 | 首次分配、接单、交接、每轮办理及完成分段留痕。保留原截止，不用转交洗掉逾期；并发接受/取消以原有version CAS唯一提交 |
| 节点人员 | 指定审核/财务账号及接单、办理、审核、财务期限；人员按既有菜单/功能过滤，服务端重验。进行中已指定节点不能静默换人，缺人可首次补指定 |
| 自审保护 | 默认禁止承办人审核自己的明细；确需业务批准例外才设置ADM_ALLOW_SELF_REVIEW=true，不默认开放 |
| 等待跟进 | 当前持锁承办人登记等谁、原因、下次跟进及实际动作说明，不延长外部截止；清除等待后待办同步解除 |
| 个人工作台 | 自动按当前持久业务状态生成站内待办：分配/接单/办理/交接/审核/财务/跟进；本人/受管团队/全量仍逐次鉴权。这里“自动生成”不是后台主动推送 |
| 管理观察 | 当前任务、逾期、待指定、缺期限、等待；汇总在分页前计算，按姓名展示当前负荷，明确不是排名。暂停风险保留，历史/结案/作废不生成新待办 |
| 团队协调 | 受管协调人的缺人事项不会漏计；只有协调范围而无明细权限时展示协调摘要，不提供明细链接或订单/附件内容 |
| 节点材料 | 审核/财务人员按授权节点上传对应核实/分析或财务材料；不能靠完整主单可见权绕过指定人员及类别门禁 |
| 表单回填 | 补齐主单编辑的供应编码、航司、票数、人民币金额和业务大类回填，避免已有值在窗口空显 |
| 未确认时限 | 新单不再自动写PNR恢复+48小时。未填写就是未知；旧记录的既有期限保留 |

## 实际复用与组件

- 持久化复用`sibebid.adm_case_document`的JSON及原子CAS；不另建业务任务数据库。本轮无需新增DDL，已安装表仍需此前的生成列/索引基线。
- 人员复用认证账号目录、角色功能、ADM受管成员；一次配置请求复用同一目录结果，不另造全员接口。身份/错误/权限公共规则提取到ADM `policy.py`，新旧动作共用。
- 公共`AccountSelect.vue`只接收业务授权的`{id,name}`选项，复用在单项/批量分配、转交和计划；不自行取全员，不做人员授权。
- `WorkflowPanel.vue`复用`FormDialog/FormGrid/DateField/FilterPanel`，工作台与详情共用；失败保草稿、版本冲突不直接覆盖、切账号清旧数据。
- 附件预览/上传、全站导出队列和原有路由/权限保持复用，未新造附件中心或导出队列。
- 已有监控通知发件箱依赖监控事件及其投递链；不伪造监控事件来声称ADM已接入。站外可靠通知适配和调度仍需后续实现。

| 表 | 源码证据与判断 | 本轮处理 |
| --- | --- | --- |
| `adm_case_document` | 当前中台正式业务入口，主单多明细/事件/附件元数据 | 直接复用JSON扩展，保留原数据 |
| `adm_dashboard_process_snapshot` | 旧ETL按adm_records.id一行，解析操作日志；含阶段、转交、无动作和质量标记；是当前流程快照，不是新系统分段责任历史 | 有价值，保留为历史核对与后续读模型参考；不直接当新流程事实库 |
| `adm_dashboard_result` | 按旧下发日、整体/航司/差异/owner聚合；成功ADM全额被算作“申诉挽回利润”，不能证明真实到账或部分减免 | 保留旧分析，不与新多明细结果混加；财务确认口径未核定前不用于正式人员评价 |
| `ads_target_progress_day` | 正被目标管理服务与ETL消费，按目标项/日期保存完成进度，不是ADM专用 | 保持原用途，不改表、不挪用 |

3. 接入既有通知端点/模板/人员映射和可靠投递，增加后台调度、去重、撤销/转交重验、失败回执及升级；确认接收人和渠道后再启用。当前只有可查询的站内待办，不含未读消息/定时推送。
4. 完成新旧主单/明细/任务映射及数据质量后，复用适用的旧快照/聚合思路建设版本化日快照；补到期任务分母、审核质量、复杂度和异议更正，先试运行，不自动综合打分或公开绩效。
