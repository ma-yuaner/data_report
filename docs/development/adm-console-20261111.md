# ADM 控制台优化与流程复核

2026-11-11 · ADM-UX-20261111。基线为 GitLab `origin/fat_cy@c393b70`，含 11 月 10 日 ADM 流程及 Excel 修订。独立工作树实施，原常用检出的未提交改动保留。

## 本轮优化

- 我的工作台对分配给当前操作员、状态为待接单的明细显示「接单」。复用详情的接单 API。服务端检查操作权限、承办人、主单及明细状态，在事务内更新明细、分配和责任记录。前端按明细防重复提交，成功后原位刷新任务和分类数，冲突时提示并重新读取。接受转派仍走原有流程。
- 统一工作台、台账、订单下钻的 Ant Design Vue 分页外观与总数，移除 ADM 原生按钮样式对分页的覆盖。台账改变每页条数后回到第一页，一次翻页只发一次台账请求。工作台每页渲染 20 条。
- 通用 Ant Design Form.Item 使用标准必填样式。ADM 自定义标签使用全局红色星号样式及 aria-required，覆盖建单、补增明细、主单和明细基础资料编辑，流程弹窗按已有服务端条件标明必填。原有服务端校验继续生效。
- 从工作台打开指定任务时，直接并行请求完整详情和配置，原来在摘要和配置返回后再请求一次完整详情。仅查看主单时仍先读摘要。台账阶段统计直接使用当前行，免去逐行回查；工作台读取失败提供原位重试。

## 分页与加载诊断

| 环节 | 源码观察 | 剩余验证或改造 |
| --- | --- | --- |
| 台账、订单下钻 | 服务端筛选、计数、稳定排序、LIMIT/OFFSET。切换时先显示页面和加载提示，结果返回后展示行。 | 在 247 用真实数据记录鉴权、首字节、响应体、可交互时间及深页 SQL 执行计划。 |
| 我的工作台 | 普通任务最多返回 1000 条，待确认转派另有上限。前端以这批数据计算多张指标卡、筛选和导出候选，再切页。GET 在查询前还处理到期提醒，可能涉及加锁、写状态和日志。 | 需要将任务筛选和分页下推到服务端，按同一权限与条件返回全量计数，并独立查询导出候选。提醒转后台需同时补偿停机积压和重试，不能直接删除读路径逻辑。 |
| 指定任务详情 | 摘要后串行完整读取已消除；直接进入任务时完整详情仍随该主单的明细与日志规模增长。 | 对单一大主单分段计时，必要时按需加载日志和附件。新增明细弹窗仍并发下载全部主单页供选择，后续应使用服务端搜索及有界候选。 |

## 业务闭环缺口

| 优先级 | 已查到的断点 | 补齐后的验收 |
| --- | --- | --- |
| 高 | 「可以结案」「转派申请」卡片使用后端统计，点击却筛选普通任务类型；普通任务映射不产生这两个类型。待确认转派有独立任务，申请人或原承办人仍缺少与卡片数一致的清单。 | 卡片计数、列表权限和结果一致，结案可直达主单并说明阻断原因，转派可查看接收、拒绝及处理结果。 |
| 高 | 编码恢复到期已有状态和日志，工作台和详情访问会触发刷新；目前缺少独立于人工访问的送达、重试和升级证据。 | 无人打开页面时仍能推进到期提醒，重复执行只产生一次有效事件，失败可查询和补发。 |
| 高 | 差异单匹配已有手工核验和 FI 未连接等结果。自动匹配周期未确认，未匹配、缺关键字段及外部系统失败后的跟进时点和责任人未形成验收证据。 | 按缺字段、暂未同步、无匹配、匹配成功和查询失败演练，确认重查时间、人工出口及结案阻断。 |
| 中 | 回款登记要求凭证号或附件，可形成中台登记记录；实际到账与财务对账仍需验证。新凭证先上传再登记，登记失败时需要识别已上传凭证并恢复。 | 验证部分回款、累计到账、重复提交、凭证恢复及与财务记录的勾稽。 |
| 中 | Excel 回传有原状态及版本校验，历史只读入口和旧 ERP 切换仍需业务证据。 | 用同一组业务样例走网页与 Excel 两条链路，核对重复、过期版本、部分成功，以及新旧数据总量和责任记录。 |

验证在主会话完成，未启用独立审查。本轮无 SQL、DDL 或调度变更。
