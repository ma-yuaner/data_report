# ADM 控制台优化与流程复核

2026-11-11 · ADM-UX-20261111。基线为 GitLab `origin/fat_cy@c393b70`，含 11 月 10 日 ADM 流程及 Excel 修订。独立工作树实施，原常用检出的未提交改动保留。

## 本轮优化

- 我的工作台对分配给当前操作员、状态为待接单的明细显示「接单」。复用详情的接单 API。服务端检查操作权限、承办人、主单及明细状态，在事务内更新明细、分配和责任记录。前端按明细防重复提交，成功后原位刷新任务和分类数，冲突时提示并重新读取。接受转派仍走原有流程。
- 统一工作台、台账、订单下钻的 Ant Design Vue 分页外观与总数，移除 ADM 原生按钮样式对分页的覆盖。台账改变每页条数后回到第一页，一次翻页只发一次台账请求。工作台每页渲染 20 条。
- 通用 Ant Design Form.Item 使用标准必填样式。ADM 自定义标签使用全局红色星号样式及 aria-required，覆盖建单、补增明细、主单和明细基础资料编辑，流程弹窗按已有服务端条件标明必填。原有服务端校验继续生效。
- 从工作台打开指定任务时，直接并行请求完整详情和配置，原来在摘要和配置返回后再请求一次完整详情。仅查看主单时仍先读摘要。台账阶段统计直接使用当前行，免去逐行回查；工作台读取失败提供原位重试。

## 台账与业务闭环续补

本节更新上面的缺口状态。续补基线 cee1f8c。

- 台账行操作改为详情或阶段明细入口。单一待办阶段直达 ADM 详情并按准确的明细状态筛选，多阶段提供阶段菜单。草稿、历史和已结束主单进入相应详情。台账阶段入口不提交状态变更，详情根据权限、承办人和实时状态显示可操作项。
- 工作台「可以结案」打开本人负责主单的分页清单，点击进入详情。详情展示结案阻断，未完成或无明细时禁用结案，后端复核同样的前置条件。
- 工作台「转派申请」对申请组长、原承办人和目标承办人开放各自记录，区分待确认与全部历史，展示接受、拒绝、原因及时间。目标承办人的可操作待办直达该明细转派页。业务状态已变化的待确认记录保留可追溯状态，关闭接受和拒绝按钮。
- 工作台增加「待匹配差异单」筛选，直达负责人跟进。显示最近及历史核验结果，未匹配、未连接或查询失败时明细保持待匹配，负责人可再次核验。自动核验周期和异常升级待业务规则明确。
- 回款跟进显示应回款、已登记与凭证记录。附件上传响应增加本次新建的附件 ID，避免并发上传时按最大 ID 错绑凭证。回款登记失败后弹窗保留已上传凭证及已填写数据，可在原弹窗重试。
- 更正上文恢复提醒观察：Compose 已包含独立的 `admwf_worker`，可在无人访问页面时推进中台提醒。模拟一次扫描失败后，下一轮可恢复处理。目标环境 Worker、站外送达、升级机制待核验。
