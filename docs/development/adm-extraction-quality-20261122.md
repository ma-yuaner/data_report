# ADM 解析输出约束与质量验收

提示词 `adm-parse-1.6`，输出契约 `adm-extraction/1.2`，校验 `adm-validation/1.5`。

## 运行时检查

- system 消息定义任务和规则，文件名、段落、定位与正文放在独立 user 消息的 JSON 值内。引号、换行、角色标记和分隔符仍是材料字符。服务端不解析这些字符为指令，也不为模型提供工具。真实模型是否受材料内容影响需用合成干扰样本验证。
- `ADM_PARSING_AI_OUTPUT_FORMAT=auto` 对官方阿里云域名的 `qwen3.8-flash` 发送严格 `json_schema`，保留非思考模式。其他地址或模型默认使用 `json_object`。已核实兼容的代理可显式配置 `json_schema`。显式 `json_object` 可用于兼容性回退。请求失败不会静默改模式或重试。现场确认接口区域、模型版本和参数透传后再确认支持情况。
- 重复键、非标准常量、截断、围栏包裹、非对象和严格模式的结构偏差会拒绝。固定键、类型与枚举由输出契约给出，未知字段值仍可按契约用 null 或空数组。服务端另查业务必填、来源、金额与日期等，正式台账仍需有权限人员确认。
- 可识别的 XLSX 同工作表 `RLOC`／`GDS_RLOC` 双列表按物理行追踪。能识别的编码行缺少对应明细、列值或同源引用时，解析校验失败并显示段落编号。同 PNR 的两行仍各自核对。明确日期标签后出现数字日期而抽取为空时提示人工核对。无固定表头、扫描件和自由文本仍依赖人工核对和抽样。
- 新解析记录保存请求模型、API 返回的模型标识（提供时）、输出格式、原始结构校验结果以及提示词与校验版本。历史保存结果可重新校验，原已登记快照按既有流程保留。旧未登记来件需重新校验才能取得本版漏抽检查记录。

## 真实材料验收

使用复核过的标注材料，固定同一组来件及判分字段。覆盖单 PDF、PDF＋Excel、其他实际使用组合、同 PNR 多行、虚拟票号、金额歧义、缺字段和失败样本。以首次完成尝试比较版本，保留失败和超时，人工修正后的台账值另行核对。

用 `python scripts/evaluate_adm_extraction.py <本地标注样本.json>` 离线评分。输入为 JSON 数组，每条包含唯一 `caseId`、`materialType`、完成尝试的解析详情快照 `task`，以及 `expected` 对象。标签使用 JSON Pointer，例如 `"/adm/amount": "471.00"`。对照前独立确定金额字符串、日期、列表顺序和预期 null；缺键判错。按材料类型比较所有关键字段，纳入必评票号类型和完整交易行时，标注对应字段及完整数组或各行。对未发送请求的失败尝试传入计划的 `outputFormat`，避免从该组分母漏计。

报告输出以下分子和分母，可从相同标签集比较同一配置下的漂移。

- JSON 对象到达率 `jsonObjects / cases`，结构匹配率 `schemaMatched / shapeMeasured`，并报告无结构测量的件数与失败原因。
- 原始与校验后字段正确率分别用 `rawCorrectFields`、`validatedCorrectFields` 除以 `labeledFields`。整单正确率为对应 `*CorrectCases / cases`，只覆盖该来件标注的字段。
- 错误放行率 `incorrectPassedGate / passedGate`。放行指解析校验通过且任务已保存。报告按请求模型、提示词、校验版本和输出格式分组，并列供应商实际返回模型标识分布。

协议或严格 Schema 校验失败且没有候选快照时，该来件的标注字段均计入分母，正确数为零。

本地专项 5 项和既有解析、组合来源、入库及规则回归 90 项通过。实际供应商解码、真实新模型抽取率和 T43 部署后的运行结果待验收。T43 发布前按既有发布约定复核后端变更并更新对应的已审 SHA256 清单。评估样本及来件快照留在受控位置。
