## 权限

账号管理的菜单/角色目录新增`risk.verification`（风控核对）；功能目录新增以下权限，可经角色继承及账号ALLOW/DENY配置。管理员沿用既有全权约定；普通账号必须同时具备菜单、view和动作权限，不因只看到菜单就获得功能。

| 权限后缀（统一前缀risk.verification.） | 功能 |
|---|---|
| view | 查看清洗结果、订单证据、核查记录和共享问题标签 |
| check | 加载清洗结果、新建核查、AI审核/分析与恢复 |
| review | 人工抽查、确认、登记问题标签及知识草稿 |
| types.manage | 新增问题分类 |
| knowledge.publish | 人工发布知识 |

前后端均校验；保留核实结果/核查记录原账号隔离，问题类型/标签沿用共享。没有新增角色自动授予所有账号，没有更改ERP写权限。部署API和Web后，在账号管理配置菜单和功能即可，无新DDL；已登录账号权限刷新沿用现有机制。
